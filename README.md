# CourtBalance

CourtBalance ist ein klickbarer Mobile-Prototyp zur ausgewogenen Planung von Tennistraining, Belastung und Regeneration.

## Live ansehen

[CourtBalance direkt im Browser öffnen](https://ynnckw.github.io/CourtBalance/)

Die Live-Version wird bei Änderungen auf `main` automatisch über GitHub Pages aktualisiert.

## Lokal starten

Voraussetzungen: Node.js 22 und pnpm 10.34.3.

```bash
pnpm install --frozen-lockfile
pnpm dev
```

Der Produktionsbuild lässt sich mit `pnpm build` prüfen.
